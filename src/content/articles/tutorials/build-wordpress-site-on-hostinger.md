## 开始前需要准备什么

| 项目 | 说明 |
| --- | --- |
| 支付方式 | 支持信用卡、PayPal、支付宝（部分地区） |
| 邮箱 | 用于注册账号与接收通知，建议用常用邮箱 |
| 域名 | 可选，Premium 及以上套餐赠送一年 |
| 建站方向 | 至少想清楚网站的定位与栏目结构 |
| 时间 | 完整走一遍约 47 分钟 |

准备好了就可以开始。

## 第一步：选择套餐并付款（约 6 分钟）

进入 Hostinger 主机的套餐选购页。你会看到 Single、Premium、Business 三档。

**对于第一个网站，直接选 Premium。** 理由很简单：它只比 Single 贵几块钱，但把可托管网站从 1 个提到 25 个、流量从 100GB 提到不限量。Single 的 1 个网站额度意味着你第二个站就必须升级。

接下来是这一步最关键的选择：**付款时长**。

| 时长 | Premium 月均 | 一次性支付 | 说明 |
| --- | --- | --- | --- |
| 48 个月 | ¥22 | ¥1,056 | 月均最低 |
| 24 个月 | ¥32 | ¥768 | 折中 |
| 12 个月 | ¥55 | ¥660 | 灵活，单价高 |

选择 48 个月能把月均价压到最低，但需要一次性付清四年。如果不确定是否长期使用，先选 12 个月验证，续费或升级时再调整。

> **注意**：所有时长都带 30 天退款保证，所以即使选了 48 个月，你仍有 30 天的反悔窗口。这是降低决策风险的实用手段。

### 在结账页输入优惠码

在付款页面找到 "Have a coupon code?"，输入我们核验过的优惠码，可以额外再省 10%：

```
30OFF
```

输入后确认订单金额确实减少了，再继续付款。

## 第二步：创建账号并完成初始化（约 4 分钟）

付款后会引导你设置 hPanel 账户。三项信息需要填写：

- 邮箱地址（作为登录名，之后无法修改）
- 密码（建议 12 位以上含大小写与符号）
- 姓名与国家/地区

提交后邮箱会收到验证邮件，**先验证再继续**，否则后续部分功能（如域名注册）会被限制。

### 一个容易忽略的设置

初始化时会问你的网站用途和建站经验。这看起来是无关紧要的问卷，但它决定了 hPanel 首页给你展示哪些快捷入口。选择"创建新网站"+"新手"，面板会优先推送 WordPress 一键安装入口。

## 第三步：绑定或注册域名（约 5 分钟）

进入 hPanel，找到「域名」模块。

### 情况 A：用套餐赠送的域名

点击「注册新域名」，输入你想要的名称。系统会实时显示可用性与价格。

首年免费，但**注意续费价格**。以 .com 为例，首年 ¥0，续费约 ¥75/年。建议在域名到期前评估：如果续费价不划算，可以转移到其他注册商。

### 情况 B：域名已在其他注册商

选择「使用已有域名」，然后有两种做法：

**做法一：改 DNS 服务器（推荐）**

在域名注册商后台，把 DNS 服务器改为 Hostinger 提供的两个地址。通常在 2 到 24 小时内生效。

**做法二：只改几条解析记录（生效更快）**

保留原 DNS 服务商，只添加两条 A 记录指向 Hostinger 的 IP。这种方式更灵活，如果你还在用原注册商的其他服务（比如企业邮箱），改 DNS 会连带影响，而改解析记录不会。

```ini
# 添加以下解析记录
A      @      你的 Hostinger IP       TTL 3600
CNAME  www    yourdomain.com          TTL 3600
```

## 第四步：一键安装 WordPress（约 3 分钟）

在 hPanel 的「网站」模块，点击「添加网站」，选择：

1. **建站方式**：WordPress（不要选"空网站"）
2. **网站域名**：选择刚才绑定的域名
3. **管理员信息**：设置 WordPress 后台的账号密码
4. **附加选项**：勾选「安装 WooCommerce」如果需要电商，否则跳过

点击安装，等待约 90 秒。Hostinger 会自动完成：

- 下载最新版 WordPress
- 创建数据库与数据库用户
- 配置 wp-config.php
- 安装 SSL 证书
- 设置 LiteSpeed 缓存规则

安装完成后你会拿到后台地址（通常是 `你的域名/wp-admin`）和管理员账号。

> **常见卡点**：如果安装后访问域名显示"无法连接"，先检查域名解析是否生效。可以在命令行执行 `nslookup 你的域名` 看返回的 IP 是否与 hPanel 里显示的一致。不一致就说明解析还没生效，等一会儿即可。

## 第五步：验证 SSL 已生效（约 2 分钟）

访问 `https://你的域名`，确认浏览器地址栏显示锁形图标。

如果显示"不安全"或证书错误，通常是两种情况：

**SSL 还没签发完成。** Hostinger 的 SSL 通常在 15 分钟内自动签发。在 hPanel 的「SSL」模块可以看到证书状态，等待状态变为 Active 即可。

**浏览器缓存了旧的 HTTP 跳转。** 用无痕模式访问验证。

确认 SSL 生效后，在 hPanel 的「SSL」模块开启「强制 HTTPS」。这一步很重要——没有它，用户仍可能通过 HTTP 访问到不加密的版本，而 Google 会把 HTTP 与 HTTPS 视为两个不同页面，分散权重。

## 第六步：基础设置（约 8 分钟）

登录 WordPress 后台，有几项必须在开始写内容之前完成。

### 6.1 站点标题与副标题

设置 → 常规。站点标题会出现在浏览器标签和搜索引擎结果里，写清楚你做什么，不要用"我的网站"这种占位名。

### 6.2 固定链接结构

设置 → 固定链接 → 选择「文章名」。

这一步必须在发布内容之前做。如果先发布了文章再改固定链接，旧链接会 404，需要额外配置重定向。

### 6.3 时区与日期格式

设置 → 常规 → 时区。改为「上海」，日期格式按你的习惯调整。

### 6.4 关闭搜索引擎索引（暂时）

设置 → 阅读 → 勾选「建议搜索引擎不索引本站点」。

**在建站完成前一定要勾上这个。** 否则搜索引擎可能抓取到你尚未完成的页面，在结果里留下不完整的快照。等网站内容完善后再取消勾选。

### 6.5 删除预装内容

文章 → 全部文章，删除"Hello World"示例文章。
页面 → 全部页面，删除"示例页面"。
插件 → 删除 "Hello Dolly" 和 "Akismet"（后者可留，但需要 API 密钥才能启用）。

### 6.6 安装必备插件

插件 → 安装插件，搜索并安装：

| 插件 | 用途 | 是否必需 |
| --- | --- | --- |
| LiteSpeed Cache | 缓存加速 | 必需（Hostinger 环境最佳匹配） |
| Rank Math 或 Yoast SEO | SEO 元信息管理 | 必需 |
| WPForms Lite 或 Contact Form 7 | 联系表单 | 推荐 |
| UpdraftPlus | 额外备份 | 推荐 |
| Wordfence Security | 安全防护 | 推荐 |

LiteSpeed Cache 装好后，进入它的设置页面，点击「Presets」选择推荐配置即可，不需要逐项调整。

## 第七步：选主题并调整外观（约 10 分钟）

外观 → 主题 → 添加新主题。

选主题不要追求功能多，而要追求**轻量**。判断方法：安装后看它的要求 PHP 版本和插件依赖，能只靠本身完成布局的通常更轻。

推荐三个方向：

- **Blocksy**——原生区块编辑器友好，免费版功能完整，适合新手
- **GeneratePress**——极其轻量，代码规范，加载快
- **Astra**——上手最直观，预设模板多

选定后进入「自定义」，至少调整四处：站点标志（Logo）、主色调、页眉布局、页脚版权信息。

## 第八步：发布第一批内容（约 10 分钟）

至少创建这几个页面，它们构成一个网站的基本骨架：

| 页面 | 作用 | 建议字数 |
| --- | --- | --- |
| 首页 | 说明你是谁、提供什么 | 300 到 500 |
| 关于我们 | 建立信任，讲背景与专业度 | 400 到 600 |
| 服务/产品 | 具体提供什么，含价格或咨询方式 | 500 以上 |
| 联系方式 | 表单 + 邮箱 + 电话 | 200 |
| 隐私政策 | 合规要求，有表单或分析工具时必须 | 按模板生成 |

发布文章时，有五个字段必须填好：

1. **标题**——包含用户会搜索的关键词，不要用营销式的空洞标题
2. **固定链接**——保持简短，用英文或拼音，去掉日期和多余层级
3. **特色图片**——列表页和社交分享会用到
4. **分类与标签**——分类是层级结构，标签是交叉索引，别混用
5. **SEO 标题与描述**——用 Rank Math 的编辑框填写，描述控制在 160 字符内

## 第九步：上线检查（约 3 分钟）

在让别人访问之前，按这个清单过一遍：

```text
□ 域名解析已生效（nslookup 验证 IP 一致）
□ SSL 证书状态为 Active，已开启强制 HTTPS
□ 已取消「建议搜索引擎不索引本站点」
□ 固定链接结构已设为「文章名」
□ 所有导航链接都可点击且指向正确页面
□ 联系表单已测试提交并确认收到邮件
□ 手机端访问无布局错乱
□ 已安装缓存插件并启用推荐配置
□ 已配置至少一种自动备份方式
□ 删除了全部 WordPress 预装示例内容
```

全部勾选后，你的网站就算正式上线了。

## 上线的三件事

### 一、提交站点地图

在 Rank Math 的设置里找到 sitemap 地址（通常是 `你的域名/sitemap_index.xml`），提交到 Google Search Console 和 Bing Webmaster Tools。这一步能让搜索引擎更快发现你的内容。

### 二、配置备份

Hostinger 的 Premium 套餐是每周自动备份。如果你在意数据安全，建议额外装 UpdraftPlus，配置每天备份并上传到外部存储（如 Google Drive 免费额度）。

### 三、记住续费时间

在日历里记下两个日期：**域名到期日**和**主机续费日**。Hostinger 会在到期前发邮件提醒，但邮件容易被归入垃圾箱。提前一个月处理，可以避免服务中断，也给自己时间评估是否降级或更换。
